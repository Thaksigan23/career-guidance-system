# Screenshots

Drop your UI screenshots here using these exact filenames so they render in the
main project `README.md`:

| Filename                  | Page to capture                          |
| ------------------------- | ---------------------------------------- |
| `landing.png`             | Landing page (`/`)                       |
| `login.png`               | Login page (`/login`)                    |
| `register.png`            | Register page (`/register`)              |
| `jobs.png`                | Job listings (`/jobs`)                   |
| `job-details.png`         | Single job details (`/jobs/:id`)         |
| `student-profile.png`     | Student profile (`/student-profile`)     |
| `cv-analyzer.png`         | CV analyzer (`/cv-analysis`)             |
| `employer-dashboard.png`  | Employer dashboard (`/employer-dashboard`)|
| `admin-dashboard.png`     | Admin dashboard (`/admin`)               |

Tips:

- Use a consistent browser width (e.g. 1440px) for a uniform look.
- PNG format keeps the dark Aurora Glow gradients crisp.
- Recommended size: 1280–1600px wide.
